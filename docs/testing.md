# Testing

This page describes how SnowAnsher is tested and how to run the tests yourself.

## Running the tests

```bash
# Manual browser testing (see docs/testing.md)
```

## What is covered

Manual browser testing. There is no automated test suite; adding one (e.g. Playwright) is a possible future improvement.

## Adding tests

- Add tests alongside the code they cover.
- Prefer testing behavior over implementation details.
- Keep fixtures free of real personal data, keys, or credentials.

## Current status

Automated test coverage is a work in progress. Contributions that add tests are
welcome.
