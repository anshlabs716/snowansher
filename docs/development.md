# Development

This page describes how to set up a development environment and work on
SnowAnsher.

## Requirements

- A modern desktop browser with WebGL
- Python 3 (only to serve the files locally)

```bash
git clone https://github.com/anshlabs716/snowansher.git
cd snowansher
```
